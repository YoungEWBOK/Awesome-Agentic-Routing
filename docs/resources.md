## Resource notes

- **[Harness-Native Agentic Routing](https://arxiv.org/abs/2607.11399)**: The paper links opensquilla/opensquilla, which redirects to TokenRhythm/opensquilla. The repository hosts the broader OpenSquilla system.
- **[Hybrid LLM](https://arxiv.org/abs/2404.14618)**: Shared author repository with BEST-Route; the README identifies both methods.
- **[RouteProfile](https://arxiv.org/abs/2605.00180)**: The repository and paper use different title wording but reference the same arXiv identifier. Check revision compatibility before reproduction.
- **[LLMRec](https://proceedings.neurips.cc/paper_files/paper/2025/hash/305a5630c29aaca434e3415fc4638eb2-Abstract-Conference.html)**: The published paper, checklist item 5, reports code in supplementary material. A public repository was not located.
- **[GMTRouter](https://arxiv.org/abs/2511.08590)**: Multi-turn history is used for personalized preference modeling; this setting should be distinguished from long-horizon task-return optimization.
- **[SeqRoute](https://arxiv.org/abs/2605.25424)**: The reported evaluation uses offline session trajectories. Compare its budget-allocation results separately from live environment rollouts.
- **[Heterogeneous Swarms](https://arxiv.org/abs/2502.04510)**: The method optimizes model weights as well as collaboration roles. Its gains are not attributable solely to routing among fixed models.
- **[AgentRouter](https://arxiv.org/abs/2510.05445)**: The ACL paper links an anonymous implementation at https://anonymous.4open.science/r/AgentRouter; its contents could not be retrieved during this check.
- **[Agent-as-a-Router](https://arxiv.org/abs/2606.22902)**: The paper links https://github.com/LanceZPF/agent-as-a-router, but GitHub returned 404 on 2026-11-06. The implementation link is left unset pending a working release.
- **[MMR-Bench](https://arxiv.org/abs/2601.17814)**: The ECCV paper and expanded V2 data release use different model and dataset pools; the repository documents both. Publication metadata was checked against the Springer DOI record.
- **[AgentSelect](https://arxiv.org/abs/2603.03761)**: The former Ancientshi/AgentMatch URL redirects to Ancientshi/AgentSelect. The benchmark recommends complete agent configurations rather than measuring step-wise model switching.
- **[Conformal LLM Routing](https://aclanthology.org/2026.acl-srw.70/)**: The guarantee concerns the error rate among queries sent to the cheaper model under the stated calibration assumptions; it is not an unrestricted claim about system safety.
- **[R2R](https://arxiv.org/abs/2505.21600)**: Routing is between separate models at decoding steps, not among internal MoE experts.
- **[FusionRoute](https://arxiv.org/abs/2601.05106)**: Routing is between separate models at decoding steps, not among internal MoE experts. The method also modifies the selected next-token distribution with learned logits.

No verified implementation link is recorded for BAAR, DialRouter, ProgRouter, E³-Orch, RSI-Router, MixLLM, LLMRec, UniRoute, Causal LLM Routing, Self-REF, SeqRoute, AgentRouter, Agent-as-a-Router. Availability details are noted above where known; an unset link does not establish that code has never been released.
